# CryptoMind AI 🤖

**Crypto Analysis Chatbot** — Real-time crypto prices, technical analysis, DeFi insights, and security tips.

## Features
- 💬 Multi-language support (Bengali, English, Spanish, etc.)
- 📊 Live price charts with sparklines (CoinGecko API)
- 🔵 Base network & DeFi protocol analysis
- 🛡️ Crypto security & scam protection
- 📈 Technical indicators (RSI, MACD, S/R levels)
